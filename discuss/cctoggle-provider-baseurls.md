## 与 llmux 现有种子的差异点

- **zhipu(智谱)**: cctoggle OpenAI 端点是 `https://open.bigmodel.cn/api/coding/paas/v4`(coding plan 端点);llmux 种子用的是 `.../api/paas/v4`
- **stepfun(阶跃)**: cctoggle 用 `https://api.stepfun.com/step_plan/v1`(OpenAI) + `.../step_plan`(Anthropic),是 coding plan 套餐路径;llmux 种子用的是 `/v1`
- **kimi(月之暗面) = moonshot**: cctoggle kimi 端点就是 `api.moonshot.cn`(与 llmux moonshot 种子一致),可确认同一家
- **huoshan(火山)**: cctoggle「火山agentplan」OpenAI=`api/plan/v3` + Anthropic=`api/coding`,印证 llmux 的 coding_plan 机制(开启时用 coding 端点)
- **dashscope(百炼)**: cctoggle bailian 端点与 llmux 新增的 dashscope 种子完全一致 ✓
- **deepseek/siliconflow/moonshot**: 与 llmux 种子完全一致 ✓

> 注: zhipu / stepfun 也有 coding plan 套餐端点,如需支持可仿照 huoshan 的 coding_plan 字段机制。
